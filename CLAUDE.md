# CLAUDE.md

Project practice lives in [AGENTS.md](AGENTS.md) — read that first. This file covers
how to work in the repo, not how to write the code.

## Commits

Never add a `Co-Authored-By:` trailer to a commit message, and never credit Claude or
any other AI tool in a commit, tag, or PR description. The history stays plain, whatever
the default attribution guidance says.
